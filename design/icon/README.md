# Little Moments app icon

`Little Moments.icon` is the shared Icon Composer source for the iPhone/iPad and native macOS app targets. Both targets include it as a resource and select `Little Moments` as the primary icon. Open this document in Icon Composer to edit its four vector layers and appearance overrides.

Dark has a deeper sky and slightly dimmer foreground while retaining the warm sun. The old raster AppIcon asset has been removed. No app feature logic or planning specifications changed.
